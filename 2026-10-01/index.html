공쥬님이 꼭 있어야 하는 건 상표권 하나예요

상표권 먼저, 설치는 나중에

공쥬님 의견이 필요한 걸 먼저 끝내고, 제가 혼자 할 수 있는 설치·셋팅은 뒤로 미루는 순서예요. 피곤해지시면 상표권만 끝내고 쉬셔도 됩니다.

1. 키티티바이지영 상표권 출원둘이 · 30분
  • KIPRIS에서 비슷한 이름 있는지 검색 (5분)
  • 상품류 정하기 — 미용·네일 서비스만 할지, 화장품 판매까지 넣을지. 여기서 공쥬님 의견이 제일 필요해요 (10분)
  • 특허로에서 출원인 코드 신청 (10분)
  • 출원서 작성·제출 — 글자만 낼지 로고까지 낼지 결정 (5분)
2. 새 노트북 셋팅믿음이
  • 윈도우 업데이트, 기본 브라우저·한글 입력 설정
  • 네이버·구글 로그인, 자주 쓰는 사이트 북마크
  • 이걸 먼저 해야 다음 두 개를 여기에 깔 수 있어요
3. 블로그 자동화 셋팅믿음이
  • 새 노트북에 설치하고 네이버 로그인 상태 확인
  • 테스트 글 하나 올려보고 타이핑 속도 조절
4. AI 자동화 설치믿음이
  • 설치하고 실행되는지 확인
  • 공쥬님이 원하는 형태가 맞는지 보여드리고 피드백 받기

제가 미리 챙길 것 — 노트북(새것·쓰던것), 충전기, 공동인증서, 로고 파일, 설치파일 미리 다운로드. 현장에서 받다 시간 날리지 않게요.

🎃 할로윈 의상 준비

그런데 아직 뭘 입을지 안 정했습니다. 지금이 D-13인데, 대여든 구매든 지금 정해야 늦지 않아요.

  • 무슨 캐릭터로 할지 — 커플로 맞출지, 각자 할지
  • 대여 vs 구매 — 한 번 입고 말 거면 대여가 싸고, 사진 많이 찍을 거면 구매가 나을 수도
  • 소품·분장 — 가발, 렌즈, 페이스페인팅까지 할지
  • 어디서 갈아입을지 — 차에 두지 말고 가지고 들어가서 보관함에 넣고 화장실에서 갈아입기로 했었어요
오늘 정하면 제가 내일부터 대여샵이랑 상품 찾아볼게요. 에버랜드 할로윈 시즌엔 인기 의상이 금방 빠집니다.
